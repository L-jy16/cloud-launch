# 실습 리소스 정리 체크리스트

실습 종료 시 사용하는 점검용 체크리스트입니다. 완료된 항목만 체크하고 실제 조회 결과를 근거로 남깁니다.

리전: 서울 `ap-northeast-2` / 이름 접두어: `cloud-launch` / 추적 태그: `Project=cloud-launch`

- [ ] EC2: Terminated 상태 확인
- [ ] EBS: 종료 시 삭제 및 남은 실습 볼륨 확인·정리
- [ ] Elastic IP: 할당했다면 Release, 생성하지 않았다면 실제 목록 확인
- [ ] IGW: VPC에서 Detach 후 삭제
- [ ] Subnet·사용자 지정 Route Table·SG: 의존성 확인 후 정리
- [ ] VPC: 관련 실습 리소스 정리 후 삭제
- [ ] NAT Gateway·ALB·RDS·스냅샷: 생성한 경우 정리
- [ ] 실습 전용 키페어·IAM 액세스 키: 사용 종료 후 정리
- [ ] Billing 및 잔존 리소스: 비용 반영 지연을 고려해 확인

각 항목의 근거에는 리소스 ID, 리전, 최종 상태, 확인 시각(KST), 캡처 또는 조회 결과를 포함합니다.

## 정리 순서

1. 외부 접속 증빙과 필요한 기록을 먼저 저장합니다.
2. 이 실습에서 생성한 리소스의 ID·태그를 대조합니다. 공유 리소스는 제외합니다.
3. EC2를 Stop이 아닌 Terminate하고, 남은 EBS와 할당된 Elastic IP를 확인합니다.
4. VPC 삭제를 막는 의존성을 확인하고, IGW를 분리·삭제한 다음 Subnet·사용자 지정 Route Table·SG·VPC를 정리합니다.
5. 더 이상 사용하지 않는 실습 전용 액세스 키와 키페어를 정리합니다.
6. 리소스 조회 결과와 Billing을 확인하고, 위 표에 시각과 근거를 기록합니다.

서비스 종료 시각(KST)은 정리 결과와 함께 기록합니다. 리소스를 삭제하면 README에 기록한 외부 URL도 더 이상 응답하지 않을 수 있습니다.
